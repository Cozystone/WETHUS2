                    외부 툴 연결

                    OAuth로 계정을 연결한 뒤, 프로젝트에 연결할 문서·시트 리소스를 선택하세요.

                    연동 구조

                    1) 제공자 선택 → 2) OAuth 인증 → 3) 문서/시트 선택 → 4) 프로젝트 허브에 연결 반영

                    활동 로그 수집

                    외부 툴의 활동 로그를 프로젝트 타임라인에 반영할 수 있도록 수집 상태를 관리합니다.

                    연결된 툴 선택 필요

                    연결/동기화 이벤트는 자동 기록되고, webhook을 발급하면 외부 푸시 이벤트도 수집할 수 있습니다.

                    리더는 여기서 테스트 이벤트를 바로 남겨 실제 적재 여부를 확인할 수 있습니다.

                    수집 엔드포인트

                    외부 서비스나 relay가 이 URL로 이벤트를 보내면 프로젝트 허브 활동 로그에 누적됩니다.

                    Relay 빠른 설정

                    Google Docs/Sheets의 실제 변경 이벤트를 모으려면 Apps Script 같은 relay가 이 endpoint로 webhook payload를 보내야 합니다.

                    팀채팅

                    프로젝트 지원 AI는 프로젝트 정보/최근 활동/팀 채팅 문맥을 함께 참고합니다.
